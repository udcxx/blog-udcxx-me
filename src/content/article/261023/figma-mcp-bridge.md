こんにちは、だいちゃんです。

久しぶりに副業でコーディングのお仕事をいただけたのですが、さすがにAI慣れっ子になってしまい、イチから手作業でコーディングする気にもならないので、今回はMCPを使ってAIに任せてみる実験をしてみました。

MCP使うためにFigmaに課金して手残りが減るのも癪なので、今回は無料で利用できる [Figma-mcp-bridge](https://github.com/gethopp/figma-mcp-bridge) を使います。使ってみた結果としては、1ヶ月で完遂するのが分かってるならフルシート 3,000円/月 払っても良い気もするな、という印象でした。

## 前提条件

- macOS Tahoe / M5 / RAM 24GB
- Figma Desktop App v126.10.11
- Figma MCP Bridge v0.0.25

- Figma スターター（無料）プラン
- Google AI Proに課金
- エージェントは Antigravity を使用

今回はできる限りお金を掛けないことを目標にしつつも、AIは普段から課金しているのでそちらを使いました。

## まずは準備

サードパーティ製プラグインを使うには、デスクトップ版の Figma が必要らしいので[入れます](https://www.figma.com/ja-jp/downloads/)。

Antigravity に MCP を繋げるため `~/.gemini/antigravity/mcp_config.json` に以下を追記します:

```
{
  "mcpServers": {
    "figma-bridge": {
      "command": "npx",
      "args": ["-y", "@gethopp/figma-mcp-bridge"]
    }
  }
}
```

ちなみに、Node.js 20以上も必要らしいです。このブログにたどり着くみなさんならとっくに入っていると思うので省略します。

次に、Figmaにプラグイン「Figma MCP Brigde」を入れていきます。

まず、Githubの [リリースページ](https://github.com/gethopp/figma-mcp-bridge/releases) から最新のプラグインをダウンロードし、zip を解凍しておきます。

先ほどインストールしたデスクトップ版 Figma で、何かしらの編集権限を持つファイルを開き、下部の「アクション」アイコンをクリックし、「マニフェストからプラグインをインポート」を探し出します。（上部の検索バーに「プラグイン」とかを入れると出てきます）

解凍しておいたフォルダ内の plugin > manifest.json を選択します。

## コーディングを任せてみる

コーディングしてもらいたいデザインを開き、「アクション」アイコンから Figma MCP Bridge を選択すると、MCP Bridgeが起動します。この状態になって初めて、エージェントから MCP と通信ができるようになるらしい。

![](/images/261023_2.png)

そしたら、コーディングしてほしいページのフレームを選択して、エージェントに「Figma MCP Bridge を使って、いま選択されているフレームを index.html としてコーディングしてください」と伝えると、実際にゴリゴリコードを書いてくれます。あらかじめ AGENTS.md とかに使って良いフレームワークを指定したり、Nodeパッケージは入れないでとルールを敷いておくと、毎回言う手間が省けて良いです。

今回使用したモデルは「Gemini 3.8 Flash」の Medium でしたが、3ページ作ってもらってだいたい Five Hour Limit Remaining が 93% でした。なので、ざっくり作らせたあとに細かい修正を加えても余裕あるくらいのトークン消費量かと。

## 課題とか

無理してなるべく費用を抑えてる影響でもあるので、全てを「課題」というのはアレですが、以下のような点は気になりました。

### コーディングルールが必要

ある程度コーディング規則を作って縛っておかないと、自分が修正できないコードになってしまいそうなので、そこは注意が必要かもしれません。

Antigravity で Turbo モードにしちゃえば、夢の「AIがコーディング中に別の作業」が叶いますが、勝手にパッケージを入れたりされたら困るので、そのあたりはルールに明記しておかなきゃですね。

### 編集権限が必要

受け取った Figma データは閲覧権限しかなかったので、一旦　.fig で書き出して、自分のアカウントに取り込むことで回避しました。ある程度デザインが固まった状態じゃないと結構手間になるかも。

もし、デザインも並行で進めるような案件なら、普通に Figma に課金して公式の MCP 使える状態にした方が効率良いかもと思いました。公式の MCP 使ったことないけど。

### 触れてるレイヤーしか見れない

MCP では、いまアクティブなレイヤーの中しか見れないようです。

そのため、ページ単位でフレームなどにまとまってないとお任せするのは厳しいかも。また、「全ページやっといて」みたいな指示は難しそうでした。

### 画像の書き出しはやってあげる必要ありそう

キービジュアルなど「背景に画像・その上にタイトル」といったエリアは、タイトルごと画像として書き出された上に、タイトルをテキストコーディングされてて、結果文字が二重になっちゃう現象がありました。文字レイヤー消さずにスライスで書き出してるような感じ。

レイヤー構造の問題なのか、エージェントへの指示で防げるのか、、、まだ未検証ですが、もしかしたら文字と被る部分の画像は人間が書き出してあげる必要があるかも。

## とはいえ、今後も使い倒したい

ひと癖あるし、画像の書き出しについてはもう少し調査してみたいですが、消費するトークン量やクオリティを鑑みると、一旦AIにコーディングしてもらって、必要な箇所だけ手を加えることで、効率よく作業ができそうだなと感じました。

コーディング任せている間に、インフラ整えたり、今まで塩漬けにしてた作業に着手するなど... できればいいんですが、AIの動きを横目に YouTube 見ちゃうのが人間らしくていいよね（？）
