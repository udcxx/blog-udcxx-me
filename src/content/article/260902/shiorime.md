## Shiorimeの使い方

Shiorime は、読書中に気になったページを「スクラップ」として記録できるサービスです。無料で利用できるWebサービスとしてリリースしています。

使い方も出来る限りシンプルにしたかったので、次のような感じで使うことができます:

1. まずは本を読む。なんか良いな/記憶に留めたいな、と思ったページに付箋などで印を付けながら読んでみてください。
2. Shiorime に会員登録 or ログインする（もちろん無料！）
3. 「読書をはじめる」ボタンから読む「本」を登録する
  * 本についてるISBNを読み取って情報を自動取得します。もちろん手動での入力も🉑
4. 付箋を貼ったページを「スクラップ」として保存する
  * OCRで本文の読み取りもできます。まだ荒削りなので余計な文字が入り込んじゃうのが課題...
  * 自分の感想などのメモも同時に残せます。
5. 最後に「スクラップ」を見返して「読書メモ」を書いたら終了

ちなみに、ログイン前の [TOPページ](https://shiorime.udcxx.me/) では、ユーザーが最近登録した「本」を紹介しています。読みたい本が決まってない人はそこもチェックしてみてください。

※ ユーザー登録しても、「スクラップ」や読書メモが公開されることはないのでご安心を！最近読んでる「本」だけの公開です。

## Shiorimeで大事にしたかったこと

Shiorimeのポイントは、「スクラップ」に半自動で本文が残せることです。Shiorimeさえ見返せば、この本で自分が気になったページに書かれてたことをすぐに振り返ることができます。

他のサービスだと、自分の言葉で記録を残す必要があって、それだと文脈が分かりづらかったり、取りこぼしがあったりしそうだったり、そこを防ごうとすると手入力で本文を入れておく必要があったりしたので、ShiorimeではOCRを組み込んで本文と感想をセットで残せる仕組みにしてみました。一方、OCRの補正は手動で必要ですが...

付箋を貼りながら読み進めることすらしてこなかった僕ですが、負荷なく取り入れられる手法になっているんじゃないかなと思います。

## 技術的なところ

アプリケーション本体は Cloudflare Workers にデプロイされてて、データベースには Supabase を使っています。認証系も Supabase にお任せできたので、爆速でリリースまで漕ぎ着けることができました✨️

OCR は GCP の Cloud Vision API を使っています。対象が本なので精度はめちゃいいです。

ユーザーが増えてきたときに、インフラが従量課金制なのが不安の種ではあります😢

ということで、有料プランを絶賛用意中です。

とはいえ、無料版だけでも十分使える！と思ってもらえる状態を維持したいと考えています。
